# TimbreDrop

> **Status: early development.** This repository is being initialized. A working downloader has not been released yet.

TimbreDrop is planned as a minimal, cross-platform command-line application that extracts audio from a supported YouTube video and converts it to MP3 with [yt-dlp](https://github.com/yt-dlp/yt-dlp) and [FFmpeg](https://ffmpeg.org/).

## Planned goals

- Interactive terminal workflow for one video at a time.
- Video metadata and duration preflight checks.
- MP3 output at 96, 128, 160, or 256 kbps CBR.
- Clear download/conversion progress and actionable errors.
- Cross-platform configuration and safe output-file handling.

## Status

This is the Phase 2 project scaffold. Application functionality, automated tests, platform packaging, and release artifacts are not implemented yet.
